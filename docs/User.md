## 1. Введение

### 1.1. Область применения 
Веб-сервис предназначен для составления приемно-сдаточных испытаний (АТМ, далее – документы испытания) авиатренажера[cite: 7]. 

### 1.2. Краткое описание возможностей 
Веб-сервис предоставляет следующие возможности[cite: 7]: 
* Авторизация и регистрация пользователя[cite: 7].
* Разделение проектов на личные (для работы над ними самим пользователем) и общие (для просмотра наработок других пользователей)[cite: 7].
* Возможность полностью передать личный проект со всеми ревизиями другому зарегистрированному пользователю[cite: 7].
* Создание документа испытаний под конкретные авиатренажеры с привязкой к международным кодам (ATA или FSTD) и автоматическим подбором названий систем и подсистем[cite: 7].
* Контроль текущего состояния АТМ через систему статусов (*Черновик, В работе, На проверке, Готово*)[cite: 7].
* Быстрое наполнение документа путем перетаскивания готовых проверок и результатов из системной библиотеки[cite: 7].
* Фоновое автосохранение изменений раз в 5 минут для защиты от потери информации и предпросмотр всех разделов[cite: 7].
* Автоматическое наполнение полей титульного листа для области общих сведений, загрузка логотипов компаний[cite: 7].
* Заполнение полей компании и их сотрудников для листа согласования[cite: 7].
* Автоматическое копирование всех данных при создании новой ревизии документа и возможность просмотра старых версий без их редактирования[cite: 7].
* Экспорт готового структурированного файла формата `.docx` строго по отраслевому шаблону на выбранном языке (русском или английском)[cite: 7].
* Управление через административную панель пользователями, справочниками, основной частью конструктора[cite: 7].

### 1.3. Уровень подготовки пользователей 
Пользователи веб-сервиса должны обладать следующими минимальными навыками для работы[cite: 7]:
1. Навык составления документов испытаний для авиатренажера[cite: 7].
2. Уверенное владение современными интернет-браузерами, умение работать с современными операционными системами и сайтами[cite: 7].
3. Умение работать с загруженными файлами формата `.docx` для финальной проверки сгенерированных шаблонов[cite: 7].
4. Базовое понимание кодирования авиационных систем ATA / FSTD[cite: 7].

## 3. Описание операций 

### 3.1. Страница авторизации

При авторизации в систему на экране будет открыта форма[cite: 7]. Для регистрации необходимо заполнить поля в окне «Регистрация»: ФИО, Логин, Пароль (можно просматривать введенный пароль, нажав на соответствующую иконку)[cite: 7]. По завершении нажать на кнопку «Создать аккаунт» (рис. 1)[cite: 7]. После этого в базе данных создастся новая учетная запись[cite: 7].

![Форма регистрации](img/fig1.png)
*Рис. 1. Форма регистрации в веб-сервисе*[cite: 7]

Для того, чтобы совершить вход уже зарегистрированному пользователю в веб-сервис необходимо перейти в окно «Вход в систему» и заполнить поля: логин и пароль[cite: 7]. По завершении нажать на кнопку «Войти» (рис. 2)[cite: 7].

*Рис. 2. Форма входа в веб-сервисе*[cite: 7]

На главной странице находится управление проектами веб-сервиса: их создание, редактирование, удаление в корзину и восстановление[cite: 7]. А также разделение на личные проекты пользователя (раздел «Мои проекты») и проекты, которые создали другие пользователи в веб-сервисе (раздел «Все проекты»), поиск проектов, переключение языка и кнопка выхода сверху (рис. 3)[cite: 7].

### 3.3. Страница документов испытаний

Чтобы перейти к документам испытаний, которые содержатся в проекте необходимо нажать на кнопку «Открыть» на карточке проекта[cite: 7]. Пользователь перейдет на страницу документов испытаний, где можно[cite: 7]:
* Создать документ испытаний, нажав на поле создания[cite: 7].
* Переключить язык или выйти с сайта[cite: 7].
* Найти проект при помощи поля поиска сверху[cite: 7].
* Листать карточки, если их становится много[cite: 7].
* Вернуться на страницу проектов при нажатии на логотип «АТМ КОНСТРУКТОР»[cite: 7].

Также сами карточки документов испытаний могут быть распределены относительно их статуса для удобного просмотра (рис. 11)[cite: 7].

### 3.4. Страница редактора

Для того, чтобы перейти на страницу редактора необходимо нажать на кнопку «Посмотреть» (если проект чужой) или кнопку «Редактировать» (если этот проект создал пользователь)[cite: 7]. При переходе пользователь сразу же окажется на вкладке «Основная часть», где он сможет формировать основную часть документа, выбирая действия и проверки[cite: 7].

В верхней части страницы пользователю доступно[cite: 7]:
* Кнопка «Назад» для перехода обратно на страницу документов испытаний[cite: 7].
* Указание названия системы, код и ревизия[cite: 7].
* Строчка автосохранения, сохраняющая документ испытаний каждые 5 минут[cite: 7].
* Переключатели вкладок для заполнения разделов[cite: 7].
* Смена статуса карточки[cite: 7].
* Кнопки сохранения и экспорта в Word (экспортирует сформированный документ)[cite: 7].
* Переключение языка (рис. 16)[cite: 7].

![Вкладка Основная часть](img/fig16.png)
*Рис. 16. Вкладка «Основная часть» для создания основной части документа испытаний*[cite: 7]

Для формирования каждого раздела документа испытаний необходимо переходить на одноименные вкладки этих частей для дальнейшего их заполнения[cite: 7]. Все поля и названия столбцов на этих вкладках строго необходимы для правильного формирования документа испытаний[cite: 7].

## 4. Ситуации, при которых возникают ошибки 

В веб-сервисе предусмотрены специальные уведомления для предотвращения конфликтных ситуаций[cite: 7]:

| Действие пользователя | Ошибка системы | Описание / Условие возникновения |
| :--- | :--- | :--- |
| Вход с пустыми или неверными данными[cite: 7] | `Неверный логин или пароль`[cite: 7] | Появляется при попытке авторизации[cite: 7]. |
| Регистрация с пустыми полями[cite: 7] | `Введите ФИО`, `Введите логин`, `Введите пароль`[cite: 7] | Появляется точечно под незаполненными полями[cite: 7]. |
| Ввод слабого пароля при регистрации[cite: 7] | Текст-требование к безопасности пароля[cite: 7] | Пароль должен содержать минимум 8 символов и латинские буквы (a-z)[cite: 7]. |
| Дублирование проекта или АТМ[cite: 7] | `Создать проект/АТМ не получится. Такой проект/АТМ уже есть`[cite: 7] | Возникает, если сущность с таким именем уже существует в базе[cite: 7]. |
| Передача проекта без указания логина[cite: 7] | `Поле login обязательно для заполнения`[cite: 7] | Появляется в модальном окне передачи[cite: 7]. |
| Передача проекта несуществующему юзеру[cite: 7] | `Ошибка. Пользователь не найден`[cite: 7] | Возникает при отправке формы передачи[cite: 7]. |
